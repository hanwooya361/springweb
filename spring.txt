HTTP: 문서 교환 규칙, *무상태*(저장기능이 없음), 연결구조X
    - 서버가 먼저 요청X, 서버한테 요청하고 응답하고(단방향 통신)
    - 장점: 다수 요청 처리, 서버 부하 줄일 수 있는 성능 이점
SOKET: 상태가 있음, 연결구조
   -  양방향 통신
HTTPS: 인증과 암호화 한 웹 프로토콜

HTTP header
    - GET(조회), POST(저장), PUT(수정), DELETE(삭제)

HTTP Content-Type
    - JSON, HTML, FORM, MULTIPART

[2] WAS

Static pages: html, css, script

Dynamic page: jsp, react, servlet
    - servlet 클래스: http를 java에서 사용할수있게 구현한 클래스 (자바 기술), apache tomcat은 spring boot web에는 내장 됨, 8080
                      동적 실행, 웹컨테이너에 의해 관리, 스레드로 동작, mvc패턴의 controller, 상속받아 구현해야함

WAS(Web Application Server)
    - Web Server는 정적 컨텐츠(html.css.script) 제공 하지만 동적 컨텐츠(jsp, servlet)는 요청(Web Container)
    - WAS = Web Server + Web Container
    - Controller 같은 기능 수행

* 어노테이션:
1	@SpringBootApplication	Spring 실행할 때 spring에 필요한 기본세팅( 1.내장톰캣지원 2. 서블릿자동등록 )
2	@RestController	"Spring 에서는 서블릿을 상속이 아닌 @Controller 어노테이션으로 지원( HTTP )
+ RestController ( HTTP content-tpye 자동으로 application/json 세팅 )"
3	@PostMapping( "/board/save" )	만약에 HTTP 요청이 POST 이면 해당 메소드로 연결 + URL만들기(중복불가능)
4	@GetMapping( "/board/findall" )	만약에 HTTP 요청이 GET 이면 해당 메소드로 연결
5	@PutMapping( "/board/update" )	만약에 HTTP 요청이 PUT 이면 해당 메소드로 연결
6	@DeleteMapping( "/board/delete" )	만약에 HTTP 요청이 DELETE 이면 해당 메소드로 연결
*	HTTP 테스트는 Talend API / POSTMAN 에서 진행!

스프링 프로젝트내 
    src->main->java-> 자바파일(controller등) = 서블릿 (동작서버/웹컨테이너)
        src->main->java->example->day02->BoardController->@GetMapping("/board/findall")

    src->main->resouces->static(html/css/js등)-> 정적파일/웹서버

        통신경로: http://127.0.0.1:8080/day02/index.html

어노테이션

리플렉션: 런타임환경에서의 클래스 구조를 읽고 객체 조작할 수 있는 기술
    1. new String(); [개발자가 직접]
    2. Class.forName(); [실행중에]

롬복:
    @NoArgsConstructor  // 매개변수 없는 생성자 (자동)생성
    @AllArgsConstructor // 전체 매개변수 있는 생성자 (자동)생성
    @RequiredArgsConstructor    // final 멤버변수의 생성자 (자동)생성
    @Getter @Setter // private 멤버변수의 getter/setter 메소드 (자동)생성
    @ToString       // 멤버변수 문자열 출력 메소드 (자동)생성
    @Data   // setter + getter + RequiredArgsConstructor + toString 묶음
    @EqualsAndHashCode  // 객체내 멤버변수의 값 모두 비교 메소드 (자동)생성
    @Builder    // 빌더 패턴 지원
